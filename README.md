## Instalacja i uruchomienie

Aby zainstalować aplikację należy sklonować to repozytorium, lub pobrać całość jako ZIP.  
Następnie w terminalu, w głównym folderze projektu wykonać komendę:  
`docker compose up --build -d`  
Aplikacja otworzyć przez przeglądarkę pod adresem `http://localhost:5173/`
